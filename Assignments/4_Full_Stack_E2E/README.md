# Full Stack Multimodal Agent - Personal Expense Assistant

## Description

This project is a full-stack multimodal AI agent application built using Google Agent Development Kit (ADK) and Gemini 2.5 Flash. The Personal Expense Assistant helps users manage their expenses by processing receipt images, extracting structured data, and providing intelligent search and analysis capabilities.

The application demonstrates a complete AI agent system with:
- **Frontend**: Gradio-based chat interface with file upload
- **Backend**: FastAPI service managing agent execution and sessions
- **Agent**: ADK-powered agent with custom tools for receipt management
- **Database**: Firestore with vector embeddings for RAG (Retrieval Augmented Generation)
- **Storage**: Google Cloud Storage for receipt images

Key features include multimodal image understanding, automatic data extraction from receipts, semantic search using vector embeddings, metadata filtering, and expense analysis through natural language queries.
